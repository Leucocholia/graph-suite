# Total orders

A total order is a linear arrangement of the \(n\) labelled vertices.

Species expression. The species is \(\mathrm{SEQ}(X)\) in labelled language: every permutation of the labels is one structure.

Visual encoding. This module renders each order as a directed comparison graph. If \(a\) appears before \(b\), then the graph contains the edge \(a \to b\). The picture is the transitive closure of the order.

Count. There are \(n!\) frames.

Ordered vs unordered. A total order is maximally ordered: swapping two labels usually gives a new structure. Its unlabelled shadow is tiny by comparison, because there is only one linear order shape of each size.

Try this. Compare this preset with the Hasse variant. The frame count is identical, but the visual encoding changes from every comparison to only adjacent covers.
